# Box Anime

A React-based anime discovery interface for browsing anime content and exploring recent releases.

## Features

- Anime browsing interface
- Search for episodes or titles
- Responsive layout for desktop and mobile
- Tailwind CSS styling
- API requests with Axios

> The feature list reflects the project's documented scope. Verify API availability and current functionality before relying on the application.

## Tech Stack

- React
- Tailwind CSS
- Axios
- JavaScript

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/Pankaj12222674/Box-Anime.git
cd Box-Anime
npm install
npm run dev
```

Open the local URL printed by the development server.
